For part 1, my proposal was based on COLEFIT, a gym that was started in 2023 to help people improve their health, fitness and confidence while being part of a supportive community. The main purpose of the proposal was to create a website that could help COLEFIT become more known, attract new members and make it easier for people to get information about the gym. I included different sections such as the homepage, About Us, Memberships, Services and Contact Us, where visitors could find information about the gym, its membership options, training programmes, facilities and contact details. I also looked at the Virgin Active South Africa website to see what worked well and what could be improved. The website was planned to be simple to use, easy to navigate and mobile-friendly, and it was going to be developed using HTML with a domain name and web hosting. The project was planned to take five weeks, from research and planning to the final submission, with an estimated cost of R13 450.

For part 2, I made some changes to improve my website and make it look better and more complete. I added CSS to all five pages and added colour to the website using black, white and red. I also changed the font to Aptos and made some changes to the headings, navigation bar and footer. I made my pictures smaller so they could fit better on the pages and adjusted the spacing and layout to make everything look more organised. I also worked on the contact form and added a red submit button. I made the website responsive so that it could work better on different screen sizes, especially on phones. I also added comments to my different pages to explain the different sections of my HTML code and make it easier to understand.
